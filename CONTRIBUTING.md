# Contribuindo para o Gerador de Placas 3D

Obrigado pelo seu interesse em contribuir! Nós damos boas-vindas a contribuições de todos os tipos.

## Como Contribuir

1.  **Fork o repositório**: Crie uma cópia do projeto na sua conta GitHub.
2.  **Crie uma Branch**: `git checkout -b feature/MinhaNovaFeature`.
3.  **Faça suas alterações**: Implemente sua funcionalidade ou correção de bug.
4.  **Commit**: `git commit -m 'Adiciona nova funcionalidade X'`.
5.  **Push**: `git push origin feature/MinhaNovaFeature`.
6.  **Abra um Pull Request**: Descreva suas alterações e envie para revisão.

## Relatando Bugs

Se você encontrar um bug, por favor abra uma **Issue** no GitHub com:
- Descrição detalhada do problema.
- Passos para reproduzir o erro.
- Logs ou screenshots (se aplicável).

## Padrões de Código

- Mantenha o estilo de código consistente com o projeto existente.
- Comente seu código onde necessário para clareza.

Obrigado por ajudar a melhorar este projeto!
